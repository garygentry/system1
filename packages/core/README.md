# @garygentry/system1-core

The engine behind the [`decide`](https://www.npmjs.com/package/@garygentry/system1) CLI, as a library: model profiles, transport, sources and splitters, egress excludes and scrubbing, fixtures for replay, the spend ledger, projection, and the spec format.

```ts
import { createContext, runMany } from "@garygentry/system1-core"
```

The CLI bundles its own copy, so install this only to build on the engine directly.

Documentation: **https://github.com/garygentry/system1**
