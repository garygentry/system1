# @garygentry/system1-pi

The `decisions` skills, packaged for [Pi](https://github.com/badlogic/pi-mono).

```sh
pi install npm:@garygentry/system1-pi
npm i -g @garygentry/system1   # the `decide` CLI the skills run
```

The skills teach an agent when to hand a closed judgement to a decision model and how to ask it well: `ask` for everyday calls, `design` to save a question as a spec, `setup` to get set up.

Documentation: **https://github.com/garygentry/system1**
